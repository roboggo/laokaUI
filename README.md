# 老卡墨水屏桌面（InkDesktop）v1.4

给汉王 Clear7 Turbo+（设备型号 HANVON P7，Android 14，1264×1680，330dpi）做的轻量桌面 Launcher，用来替代原厂桌面。

## 成品

- APK：`build/InkDesktop-v1.4.apk`（约 24KB，已签名，v2/v3 签名）
- 应用名：老卡墨水屏桌面（包名仍为 `com.inklauncher.minimal`）
- 包名：`com.inklauncher.minimal`
- minSdk 24 / targetSdk 34

## 界面结构

- **首页**：顶部时间日期（居中、时间 144sp / 日期 36sp、约占屏幕 32%）＋ **8 个**常用应用 4 列 96dp 大图标（4×2 整体在图标区居中）＋ 底部三块 tab。无电量显示、无「设为桌面」。
- **底部三块 tab**（仅首页显示）：左「系统设置」（汉王）／中「全部应用」（大，1:2:1）／右「安卓设置」（原生设置）。
- **全部应用页**：顶部「← 返回 / 管理首页 / 排序首页 / 设为桌面」＋ 搜索框 ＋ 刷新 ＋ 全部应用 5 列 72dp 网格。

## 功能与操作

- **时间日期**：居中，时间 144sp 加粗、日期 36sp（均比初版放大约 50%），顶部区域约占屏幕 32%，实机确认时间、日期都完整在屏幕内。
- **底部三 tab**：点左「系统设置」打开 `hanvon.aebr.hvsettings`，点右「安卓设置」打开 `com.android.settings`，点中间「全部应用」进入应用列表页。
- **首页 8 个应用**：默认 8 个（Wi-Fi传书、微信读书、喜马拉雅、京东读书、老卡书库、文件、文本记事、系统设置）；从 v1.3 升级时会自动重置为这 8 个（配置版本 v2）。以后仍可自由增删，但总数上限 8 个，加满时会提示先移除一个。
- **自由选择首页应用**：
  - 在更多应用页点「管理首页」→ 每个应用名前显示 ✓（在首页）或 ·（不在首页）→ 点一下即加入/移出首页 → 点「完成」保存。
  - 首页长按应用可「从常用移除」；更多应用页长按可「添加到常用/从常用移除」或看「应用信息」。
- **首页排序**：更多应用页点「排序首页」→ 弹出带序号的列表 → 点某个应用把它上移一位，反复点排到想要位置 → 点「完成」。顺序会持久保存，重启不变。
- **搜索**：更多应用页按应用名或包名过滤。
- **刷新**：重新读取应用列表。
- **设为桌面**：入口在全部应用页 header，引导把本应用设为默认桌面（Home 键选择，或跳系统设置）。
- **返回**：更多应用页返回首页；返回键在更多页返回首页、首页不响应。

## 墨水屏优化点

- 纯白背景 + 纯黑文字，无渐变、无阴影、无动画（Manifest 主题里禁用全部窗口动画）。
- 图标在内存里做像素级灰度转换后缓存，避免 ColorFilter 在汉王定制渲染链上失效。
- 原生 View 构建 UI，不依赖 AndroidX / WebView，APK 极小、内存占用低。
- 单个坏应用（如失效的预置 APK）的标签加载异常会被隔离，不会让整个列表加载失败。

## 安装与设为默认桌面

```bash
adb install -r build/InkDesktop-v1.4.apk
```

设为默认桌面二选一：
1. 按设备 Home 键 → 在弹窗里选「墨屏桌面」→ 选「始终」；
2. 在全部应用页点「设为桌面」→「打开系统设置」→ 手动选择。

## 重新构建

本机原本无 JDK，已下载免安装 Temurin JDK 17 到工作区 `.toolchain/`，不污染系统。构建脚本直接调用 Android SDK 工具链（aapt2 + javac + d8 + apksigner），不联网、不需要 Gradle：

```bash
cd ink-launcher
./build.sh
```

- keystore：`debug.jks` 放在项目根目录（不随 build 清理），保证多次构建签名一致，可覆盖安装。
- 若覆盖安装提示签名冲突：`adb uninstall com.inklauncher.minimal` 后再装。
- 修改源码后重新运行 `./build.sh` 即可。

## 已知限制

- 应用图标依赖各应用自身资源；少数系统应用标签显示为长包名（系统本身如此）。
- 排序为「点上移」方式，没有拖拽；应用多时需要多点几次，但胜在墨水屏上刷新少、可靠。
- 底部三 tab 只在首页显示，进入全部应用页后靠「← 返回」回首页。
- 未做开机自启动或系统级替换；设为默认桌面完全走 Android 标准 HOME 机制，不需要 root。
